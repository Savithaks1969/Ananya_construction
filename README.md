# Ananya Construction Website

A professional website for Ananya Construction, showcasing construction and interior design services.

## Features
- Modern, responsive design
- Service showcase
- Project portfolio
- Contact information
- Leadership team profiles

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Python HTTP Server for local development

## Running Locally

1. Start the local server:
```bash
python -m http.server 8080
```

2. Open your browser and navigate to:
```
http://localhost:8080
```

## VS Code Debugging

This project includes VS Code launch configurations for debugging in Chrome. Press F5 or use the Run and Debug panel to launch.

## Project Structure
- `index.html` - Main website page
- `style.css` - Styling and responsive design
- `script.js` - Interactive functionality
- `img/` - Image assets
- `logo.jpg` - Company logo
- `HOW_TO_UPDATE.md` - Guide for updating website content
